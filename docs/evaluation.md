실행 명령:

```bash
npm ci
npm run build
npm run eval:retrieval -- --scorer legacy --out ./eval-legacy.json
npm run eval:retrieval -- --scorer bm25f --out ./eval-bm25f.json
```

아래 표는 결과 JSON의 수치 문자열을 반올림 없이 옮겼습니다. 같은 프로세스의 환경·색인·강화 조건이 지연에 영향을 주므로 다른 기기의 성능을 보장하지 않습니다.

## 차트와 지표

<img src="assets/retrieval.svg" alt="2026-10-21 픽스처 평가: legacy와 BM25F의 exact·crosslang·paraphrase all 분할 Recall@1·Recall@5·MRR">

차트는 아래 표의 `all` 행만 사용합니다. Recall@1·Recall@5는 정답 집합에 대한 상위 k개 회상 비율, MRR은 첫 정답 순위 역수의 평균입니다. 하네스의 계산 정의는 `scripts/eval-retrieval.mjs`를 따릅니다. 차트의 Recall은 100을 곱해 소수 첫째 자리, MRR은 소수 셋째 자리로 반올림하며 막대 길이는 원수치입니다. none은 정답이 없는 질의이므로 이 차트에서 제외합니다.

## 전환 판단 기준

수치 표와 차트는 `eval/fixture-vault`에 대한 단일 질의 어휘 검색 결과입니다. 벡터와 자동 회상은 기본 꺼짐이며 이 측정으로 활성화 효과를 주장하지 않습니다.

### 벡터·BM25F·그림자 계측

벡터 검색·다중 질의는 이 수치의 측정 대상에 포함하지 않습니다. legacy의 지연에는 기본 그림자 계측이 포함되므로 BM25F와의 차이를 순수 알고리즘 비용으로 해석하지 않습니다. 벡터의 저장·융합·강화 계약은 [기억 모델](memory-guide.md#선택형-벡터-계층)을 따릅니다.

벡터 계층의 기본 활성화에는 아래 네 조건을 모두 충족해야 합니다. 전환 조건 미충족으로 기본 꺼짐을 유지하며, 위 어휘 검색 표를 벡터의 전환 판정으로 사용하지 않습니다.

- paraphrase Recall@5: 어휘+다중 질의 대비 McNemar p<0.05의 유의한 상승.
- exact Recall@1: holdout 기준 대비 하락 없음.
- none 질의 오탐률: 증가 없음. 코사인 하한 τ는 tune에서 정하고 holdout으로 판정.
- 한↔영 정답 쌍 판별 AUC ≥0.9.

BM25F의 기본값 판단에는 정답 질의 holdout의 McNemar 검정으로 유의한 개선 여부를 확인하며, MRR 상승만으로 전환하지 않습니다. 기본값은 `legacy`입니다. BM25F는 점수 척도가 다르므로 자동 회상 하한 `ASTRONRAG_AUTO_MIN_SCORE`를 별도로 정해야 합니다.

### 훅과 자동 회상

자동 회상의 품질 기준은 무관(none) 질의 오탐률 ≤10%와 exact Recall@1 ≥0.8을 동시에 충족하는 것입니다. 끝단 지연 기준은 훅 끝단(spawn~종료, 프로세스 기동 포함) p95 ≤200ms입니다. 두 기준을 모두 충족해야 기본 활성화 대상으로 판단하며, 현재는 전환 조건 미충족으로 기본 꺼짐을 유지합니다.

품질 평가와 끝단 지연 측정 명령:

```bash
npm run eval:autorecall
npm run bench:autorecall -- --count <N>
```

`<N>`은 합성 볼트의 기억 수입니다. 품질 평가는 기본으로 `eval/autorecall-fresh.jsonl`을 사용하며, `npm run eval:autorecall -- --queries eval/autorecall-judge.jsonl`로 판정 질의 집합을 지정합니다. 기억 원본은 `eval/fixture-vault`입니다. 품질 평가는 `main.none.rate`와 `main.exact.r1`, 벤치마크는 주입·비주입 사례 중 가장 큰 훅 끝단 p95(`worstP95`)를 기준과 대조합니다.

위 단일 질의 평가의 점수 임계는 실제 훅의 주입 효과를 보장하지 않습니다. 흔한 영어 단어 매칭의 오탐과 매 프롬프트 프로세스 기동 비용이 한계입니다. CLI·데스크톱 Code 탭·VS Code 확장의 실제 주입 효과는 별도 검증이 필요하며 스크립트 출력 회귀와 구별합니다.

### 파일·SQLite 동시 사용 근거

어휘 회상의 품질·지연 표는 동시 사용 안전성의 시험 결과가 아닙니다. 저장소별 트랜잭션·재시도·경합 한계는 [동시 사용 안전성](operations.md#동시-사용-안전성)을 따릅니다.
